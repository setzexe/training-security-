# Watering Hole Attacks

What if a current organization is so well protected that stuff like phishing or USBs do not work? Attackers might instead try to execute what is known as a **watering hole attack**. Attackers target the next application or site that an organization or victim will use in a way that this victim would not even see coming.

This requires research. An educated guess is needed on where the victim will go based on context. They can infect these sites and make them vulnerable, or attacking that site via email directly.

The attacker might poison the water for everyone that visits this site. But the main thing they care for is the main victim.

## Watching the watering hole

Unfortunately, there is not really one single thing to prevent these. Preparing in advance via firewalls or anti-virus's help malicious data entering your own network. Although really only for super sketchy cases, pretesting via a burner computer could help too.

# Other Social Engineering Techniques

Misinformation / disinformation in itself (as common as it is) is social engineering. You could see it as socially engineering hate or misinformation into people. This is meant to create division and confusion.

There are often nation-state actors via politics involved. Politics and the internet play a heavy role in all this. Divide, distract, persuade. 

Advertising can do this exact same thing. Not just advertising. Social media is what enables all this to be as heavy as it is in the first place.

A lot of misinformation starts like this:

Create fake users to create content to post on social media --> Amplify message --> Real users see and share this message

## Brand Impersonation

This is just impersonation on a brand level. This does not just refer to phishing emails impersonating a brand. This also includes malicious ad's or sites or popups that just slap a brand logo on it. 

Especially with sites, typos happen. Attackers can buy the domain for common typo's an inject those with malicious data.
