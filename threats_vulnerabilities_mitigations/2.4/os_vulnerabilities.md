# Operating System Vulnerabilities

Operating Systems are a foundational part of the digital world. Every device has one. Your phone, PC, laptop, smart watch, etc. This makes the OS a big target.

Operating Systems are extremely complex. There are millions upon millions of lines of code. More code = more security issues. There are actually probably hundreds of vulnerabilities that exist already; the code is simply too complex for researchers or attackers to find them easily.

Windows typically updates the OS once every month (2nd Tuesday every month). While not a standard for the industry, many companies have similar schedules. This update is typically one big update bundled with a bunch of smaller updates / patches.

## Best practices for OS vulnerabilities

It is important to always update the OS. The monthly updates or on demand updates are heavily recommended. When attackers realize what an update was patching, they may attempt to attack systems that are still vulnerable to this.

A patch might break something else though. There can be a few ways to prevent this. The main (and this really applies to big updates with big stakes as a whole) way is testing. Otherwise, a fallback plan like a reboot and backup works too.
