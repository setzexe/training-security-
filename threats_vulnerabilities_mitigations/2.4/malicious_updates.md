# Malicious Updates

As mentioned before, frequently patched / updated systems are more up-to-date. These updates typically come with bug fixes and security patches as the cyberscape grows.

This process in itself does have its own security concern, as not every update is equally secure. It's best to follow the best practices behind this; have a proper backup and install from trusted sources. 

## Downloading and Updating

Updates are typically installed from a downloaded folder. It's important to consider each update installation as it can be malicious.

Confirm the source. A default should be visiting the developer's site directly, or at least a legitimate repo / site for the update or service. A random pop up or update file from a random website probably is not very trustworthy.

Many operating systems will only allow signed apps that are digitally signed. It is not typically worth disabling security controls to go around this.

## Automatic updates

Sometimes, apps will update themselves. These updates are relatively trust worthy; they come directly from the developer and often include digital signatures.

This still can come at risk though. While risk is lower, the scale of damage could be way more if an attack happen if any instance of that application is infected.
