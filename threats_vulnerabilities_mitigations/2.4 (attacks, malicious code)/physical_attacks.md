# Physical Attacks

This is not only refering to hardware. This literally means attacks within the physical world. No keyboard, no command line, just physical contact in some capacity. 

If someone gets physical access to a server, it might be game over. This person will have full control; no level of cybersecurity can protect it at this point.

## Common physical attack forms

- Brute Force
  - Where the cybersecurity term comes from. Similar concept; retry and retry until you get in. In this case, being physical with the door.
  - Windows, doors, any entry point will be pushed, kicked, guns potentially, etc.
- RFID Cloning
  - These work as authentication cards / keys. They allow anyone with that ID to access an area.
    - It is not difficult to steal or clone one of these. Cloners exist on Amazon for $50.
  - It is recommended to use **MFA (Multi Factor Authentication)** with RFID's.
- Environmental Attacks
  - This relates to where alot of the hardware in a network can be found. Attacking this via weapons or unplugging cables tinkers with the network.
  - HVAC (Heating, Ventilation, AC) and humidity controls must be maintained as well; temperature and environment directly affects the utility of these devices.
  - Smoke and fire suppression / prevention too.
