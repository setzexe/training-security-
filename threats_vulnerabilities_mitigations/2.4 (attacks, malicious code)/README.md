# Malicious Code

Very broad, but this is just as the name implies; malicious code. Code that can cause harm for the user. Executables, scripts, worms, etc.

There are many techniques that do not require heavy technical skill; default credentials, brute force, social engineering, etc. This often is not the best for getting into well-secured systems. This is where code comes in. This requires alot more technical skill.

The fact that there is so much malicious code means there needs to be alot of cybersecurity layers to back it up. Not only stuff regarding the main security controls but logical stuff like firewalls. Continuous patches / update. Antivirus. Secure computing habits. And the list goes on.

# Malware

Malware generally refers to software that is doing bad things to your system. Gathering and sending keystrokes to attackers, sending you advertisements, viruses, worms, anything bad.

Malware includes alot of different types. Viruses, worms, ransomware, trojan horse, keylogger, spyware, all bad. Very bad. These can encrypt data, steal data, etc.

## How you get malware

Malware typically works as a system. Something like a **worm** will take advantage of a vulnerability and can, from that point, possibly add other software or change configuration to allow more vulnerabilities.

This malware typically needs to be loaded on the computer. Perhaps as an email link or web page pop. Or a downloaded file without you clicking it (drive by downloads). As mentioned earlier too, OS's have vulnerabilities; updates are necessary.

## Purpose of data

Personal data and organizational data is valuable. Credit card information, SSN's, bank details, all of it has a value. Organizational data is worse because it often handles mass amounts of personal data along with stuff that could hurt a company too, like an employees credit card info as well as VPN key's they have for a company.

## Ransomware

Ransomware in particular shows this in full affect. This can be accessed by typical malware access (links, downloads, etc). Once infected, your pc gets practically bricked **unless** you provide crypto. The malware will encrypt your data and that payment is the only way to decrypt this data and access the computer. **WannaCry** is the biggest example of this. This is a very unfortunate use of public-key encryption.
