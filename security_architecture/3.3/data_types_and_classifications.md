# Data Types and Classifications

Data is the main thing attackers want. However, there are different types of data.

## Data Types

**Regulated** data is managed by a third party and follows government laws and statutes that can affect how data is stored.

**Trade secrets** are known ONLY to the organization. Many other people or organizations would LOVE this. Important to keep secure.

**Intellectual property** can be viewed by others, but is owned by a corporate. Copyright law typically supports this.

**Legal information** are related to court records and documents, judge and attorney, etc. PII (personally identifiable information) may be stored in a seperate format if this is needed to be kept private.

**Financial information** regards information with money. Internal company financials, customer financials and payment records, etc.

Some data types will be **human-readable**. Spreadsheets and whatnot. Other types might be unreadable: barcodes, encoded data, XML / CSV (moreso a combination of readable and nonreadable), etc.

## Classifying Sensitive Data

Not all data has the same level of categorization. Stuff like license tags could be publically available, but serious health data should stay private. Therefor, different levels will require different levels of security or handling.

**Proprietary data** is data that is the property of an organization, usually involving trade secrets.

**PII (Personally Identifiable Information)** is data that can be used to identify an individual. Name, date of birth, mother's maiden name, biometric information, etc.

**PHI (Protected Health Information)** is health information associated with an indivdual. Health payments, records, status, etc.

**Sensitive** data is important data. Intellectual property, PII / PHI, financials, etc.

**Confidential** is very secret and must be approved to view.

**Public / unclassified** would not have any viewing restrictions while **private / classified** would.

**Critical data** means data that should always be available.
