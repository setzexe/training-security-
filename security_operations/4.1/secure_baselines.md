# Secure Baselines

A secure baseline is a documented set of security settings a system should have. This should be applied throughout the entire system. It defines what 'properly secured' looks like; firewalls and its rules, security updates and vendors, OS / application settings, allow / deny lists, so on and so forth.

There are three main steps with forming a secure baseline.

## Establish

Decide the required settings. Manufacturers often provide users with a starting basline that can be adapted to an organization. Obviously, this should be tested. Settings are not just for security; they can also affect how you use the app and the use of a service.

## Deploy

Apply these settings acros devices. Group policy is popular for Windows as it is easy to group users. **MDM (Mobile device management)** manages mobile devices.

## Maintain

Regularly check that systems still follow this secure baseline. There should be no reason for a system to fall under this.

It can be assumed that vulnerabilities will grow and a baseline might not be proper enough. Updating the baseline based on this is important.
