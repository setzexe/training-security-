# Physical Security

As implied previously, cybersecurity not only involves digital security but physical security as well. This is relatively straight forward.

Many things we use for physical security, we already rely or see in a daily life. Locks, barricades, doors, etc. Fences too, especially with barbed wire. You can see through them but still provide a decent level of security. This can be put to the extremes too; concrete walls, moats, etc.

The **safety and accessibility** are important factors as well.
- How should the access points be? Who and what (cars?) can access this entry point?
- How do we minimize injuries and ensure ease of use?

## Indoor Physical Security

With indoors physical secrity, it only gets more important. Badge checks, authentication, etc. Organizations will often utilize a **access control vestibule**. This is typically a room or area that is meant to manage access control based on how its accessed.

In the most common example, a school or business entry building. You need to be able to access that first door before you can access the rest. This is applied to more specific scenarios.

## Video Surveillance && Sensors

This is a huge help with physical security. CCTV (closed circuit television) can replace guards that do not attack. You can add a lot to a CCTV as well; motion recognition, object / facial recognition, etc. Sensors have this same concept applied to them, but with motion / particles.

It is best recommended to have multiple cameras handled over one monitoring system.

## Security Guards

This is also a bonus. Physical protection that can also validate the identification of anyone. This helps a lot as in most organizations, you are required to wear an ID badge of some sort. Security guards help verify this.

You will often see security guards in pairs of two's, or at least never only one. This ensures checks and balances in terms of security.

## Lighting

You obviously need to see. Better lighting = better visibility = less deceptive to threats. Non infared cameras see better.
