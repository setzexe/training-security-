# Gap Analysis (General Cybersecurity)

Gap analysis is the study of the points between where we are and where we want to be. The gap between these two points.

In security, this is extremely common. If the start point is a data breach and the end point is eliminating the target, then the gap analysis is not just, "Where is the target?", it's also "How do we stop them?", "What attack surface did they enter from?" so on and so forth.

There is *a lot* to consider with gap analysis. It's not necessarily super deep knowledge. it's just a *very* large base.

# Gap Analysis (Managerial Security)

This moreso regards an entire organizations gap analysis. If the current point has unwanted results, and the end point is wanted results (more security knowledge, better staffing, etc) then there is a lot to do in between that to achieve that goal. 

This can require extensive research and can take weeks or months. As much information is needed to get accurate assessments. Emails, data gathering, technical research, multiple participants, etc. Everyone should work towards a known baseline / set of goals.

For the end goal, there are known formal standards that can be used such as ISO 27001.

## Evaluating people and processes

As mentioned earlier, getting as much information as you can is essential. Former experience, current training / knowledge, etc. This applies to processes too. Understand what processes you are actually working with, and connect it with current people. Within this, you can identify strengths and weaknesses. 

Now you can compare all the people and process data and have a good look at what is going right and what is going wrong. This is a **gap analysis report**. It is a formal description of the current state. From this point on, you have more clarity to make choices to reach the end goal. Team is not good at maintenance? Implement some protocol that enforces it. This may seem obvious now, but it was not known beforehand.
