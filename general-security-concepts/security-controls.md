# Security Controls

A lot of security risks out there with different categories and types to consider. Assets are also varied. It's not just data, it can be physical property or whole systems too.

Below are broad control paths that we can use to mitigate these risks.

Security controls in this case could be viewed as "controlling the (cyber)security."

## Control Categories

- Technical controls
    - These are controls that are implemented using systems. This includes firewalls, anti-virus, or policies / systems that can be used to allow or reject operating system controls.

- Managerial controls
    - Administrative controls associated with security design and implementation. 
    - Security policies, standard operation procedures.

- Operational controls 
    - Controls implemented by people as opposed to systems.
    - Security guards, but also things like awareness programs made by people.

- Physical controls
    - As the name implies, these physically control the security. Limiting physical access is the goal.
    - Guard shack, fences, locks, badge readers (authentication...)

## Control Type Examples

- Preventative (Prevents attacks)
    - Technical: Firewall
    - Managerial: Onboarding policy (set up certain things so employees don't just expose anything onboard)
    - Operational: Guard shack (security guards)
    - Physical: Locks, lences, doors

- Deterrent (Discourages attacks. Does not necessarily prevent them)
    - Making an attacker think twice is ideal
    - Technical: Splash screen (warning screen)
    - Managerial: Demotion 
    - Operational: Reception Desk
    - Physical: Warning signs

- Detective (Identifies & warns when an attempt might / does happen) 
    - Technical: System logs
    - Managerial: Review login reports
    - Operational: Property patrols
    - Physical: Motion detectors / security cameras

- Corrective (Happens after an event happens. Reverses the impact of an event)
    - You want to correct the problem.
    - Technical: Backup systems
    - Managerial: Policies for reporting security issues
    - Operational: Contact authorities
    - Physical: Fire extinguisher (assuming fire)

- Compensating (provides you with other means to control a security event, assuming you cant use main immediate fix)
    - Technical: Implement a firewall preventing use of vulnurable app until app is fixed
    - Managerial: Seperation of duties
    - Operational: Simultaneous tasks / guard duties
    - Physical: Generator for power outage

- Directive (weaker. You direct weaker security controls to stronger ones. Not really based on threats)
    - This is moreso a "Do this to prevent future attacks that MIGHT happen"
    - Technical: Store in more protected folders
    - Managerial: Create / update complience policies and procedures
    - Operational: Train users on proper security policy
    - Physical: Post signs for "Authorized Personnel Only"

## Important to know

- There are many categories of controls and most organizations will use multiple, if not all, of these. Combined, at the same time, etc.
- Each organization is different. There are many security controls out there and people should not expect for each organization to do things the exact same things as each other.
