# Blockchain

Blockchain is a distributed ledger that keeps track of transactions. It is decentralized; everyone on the blockchain maintains it. This ledger records and replicates to everyone. This tracking ability allows for many uses; payment processing, digital identification, supply chain monitoring, etc.

## Process

A transaction is requested. This could be anything, like transferring medical records, house title info, etc. The main use mentioned online is crypto. 

That request is sent to every computer within the decentralized network to be verified. That verified transaction is added to a new block of data containing other recently verified transactions.

A secure code (a hash) is then provided, which is calculated from previous blocks. The block is then added to the end of the chain of blocks, which is updated to all nodes in the network for security. The transaction at this point is complete.

If any blocks are altered, its hash and all following hashs in the chain are automatically recalculated into something unwanted. The system rejects these unwanted hashes.
